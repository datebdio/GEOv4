# GEOv4 Project Context

## Product Position

GEOv4 is an enterprise GEO Intelligence Platform.

It is not a generic AI writing tool and not only an SEO tool.

The goal is to help companies understand and improve how their brand appears in AI-generated answers.

## Target User

Enterprise marketing teams.

Examples:
- Retail brands
- Shopping malls
- Chain companies
- Service companies

## Core Value

Measure AI visibility.
Find GEO opportunities.
Create optimized content.
Track improvement.

## Main Workflow

Brand assets
→ Prompt monitoring
→ AI visibility detection
→ Citation analysis
→ Opportunity discovery
→ Content optimization
→ Publishing record
→ Effect tracking

## Current V4 Scope

Only enterprise edition.

Removed from V4:
- OEM
- Platform admin
- Billing
- Multi-tenant commercial management

## Development Philosophy

Build a real commercial product.

Avoid:
- Empty dashboards
- Hardcoded metrics
- Fake workflows
- Incomplete CRUD

Every module requires:
- PRD
- Data model
- API design
- UI
- Test
- Acceptance

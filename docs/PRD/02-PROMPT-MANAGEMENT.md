# Prompt Management PRD

## Goal

Manage the real questions used to measure AI visibility.

## Scope

- Prompt group and prompt CRUD.
- Locale, intent, funnel stage, tags and priority.
- CSV import, duplicate detection and archive.
- Provider/model selection and manual or scheduled runs.

## Acceptance

Users can import prompts, resolve duplicates, group and filter them, select a
provider set, execute a run and trace every response back to its exact prompt.

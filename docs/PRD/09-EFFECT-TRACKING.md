# Effect Tracking PRD

## Goal

Measure whether a GEO action changed AI visibility.

## Scope

- Baseline and follow-up detection windows.
- Prompt/provider comparable cohorts.
- Mention, rank, citation and share-of-voice deltas.
- Links from result to opportunity, content and publication.

## Acceptance

Users can select a publication, run or schedule a comparable follow-up and see
traceable before/after metrics without mixing mock and real responses.

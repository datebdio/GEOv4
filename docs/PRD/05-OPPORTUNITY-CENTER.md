# Opportunity Center PRD

## Goal

Turn visibility gaps into prioritized, evidence-backed actions.

## Opportunity types

- Missing brand mention.
- Competitor rank gap.
- Missing citation/source coverage.
- Weak or inaccurate brand description.
- Missing website structure or evidence.

## Acceptance

The system generates explainable opportunities from detection data, shows the
supporting responses, allows prioritization and creates a content brief.

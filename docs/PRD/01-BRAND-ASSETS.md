# Brand Assets PRD

## Goal

Create the verified brand context used by every detector and content task.

## Scope

- Brand profile CRUD.
- Website, products, services, aliases and prohibited claims.
- Competitor CRUD with aliases.
- Evidence source URL and verification status.
- CSV import/export.

## Acceptance

An operator can create a brand, add aliases and competitors, attach verified
facts, edit them with audit history, and use the saved data in a detection run.

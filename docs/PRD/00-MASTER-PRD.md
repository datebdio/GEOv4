# GEOv4 Master PRD

## 产品定位

GEOv4 是企业级 GEO（Generative Engine Optimization）增长管理平台。

目标：帮助企业监测 AI 搜索中的品牌表现，发现优化机会，通过内容优化提升 AI 推荐概率。

## V4范围

本版本只做单企业版。

不包含：
- OEM
- 平台管理端
- 多租户商业系统
- Billing

## 核心闭环

品牌资产
→ Prompt管理
→ AI可见度检测
→ Citation分析
→ 竞争分析
→ GEO机会
→ 内容生产
→ 发布记录
→ 效果追踪

## 产品原则

1. 数据必须真实可追溯。
2. AI结果必须保存原始回答。
3. 所有模块必须完整CRUD。
4. 所有功能必须有PRD和验收标准。
5. 模拟结果必须明确标识，不进入真实指标。
6. 所有聚合指标必须能够下钻到原始回答。

## 用户角色

- 企业管理员：系统设置、Provider、账号和权限。
- GEO运营：品牌、Prompt、检测、机会和报告。
- 内容编辑：Brief、证据、内容版本和发布准备。
- 审核人员：事实核验、内容审批和发布确认。

## 功能模块

1. 品牌资产与竞品管理。
2. Prompt分组、导入和监测计划。
3. Provider配置、检测任务和成本控制。
4. 原始回答、品牌排名和Citation分析。
5. 竞争差距与GEO机会中心。
6. 有证据链和版本历史的内容工坊。
7. 渠道导出、发布记录和连接器。
8. 发布前后可比检测与效果追踪。

## 验收标准

企业用户能够完成：

创建品牌 → 创建Prompt → 执行检测 → 查看AI回答 → 发现机会 → 生成内容 → 记录发布 → 查看效果变化。

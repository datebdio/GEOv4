# GEOv4 Master PRD

## 产品定位

GEOv4 是企业级 GEO（Generative Engine Optimization）增长管理平台。

目标：帮助企业监测 AI 搜索中的品牌表现，发现优化机会，通过内容优化提升 AI 推荐概率。

## V4范围

本版本只做单企业版。

不包含：
- OEM
- 平台管理端
- 多租户商业系统
- Billing

## 核心闭环

品牌资产
→ Prompt管理
→ AI可见度检测
→ Citation分析
→ 竞争分析
→ GEO机会
→ 内容生产
→ 发布记录
→ 效果追踪

## 产品原则

1. 数据必须真实可追溯。
2. AI结果必须保存原始回答。
3. 所有模块必须完整CRUD。
4. 所有功能必须有PRD和验收标准。

## 验收标准

企业用户能够完成：

创建品牌 → 创建Prompt → 执行检测 → 查看AI回答 → 发现机会 → 生成内容 → 记录发布 → 查看效果变化。
